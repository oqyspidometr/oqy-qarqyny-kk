# Оқу қарқыны

Қазақ тіліндегі дауыстап оқуды браузердің `SpeechRecognition` мүмкіндігімен өлшейтін мобильді PWA.

## Іске қосу

`dist/` қалтасын HTTPS қолдайтын кез келген статикалық хостингке орналастырыңыз. Микрофон тек HTTPS немесе `localhost` қауіпсіз ортасында ашылады.

## Мүмкіндіктер

- `kk-KZ` тілін сұрайтын микрофон арқылы сөйлеуді тану;
- таймер, оқылған сөз саны және сөз/минут есебі;
- бастапқы мәтінмен сөз деңгейінде жуық салыстыру;
- қате, артық және өткізілген сөздерді бағалау;
- нәтижені браузердің жергілікті жадында сақтау;
- орнатылатын және қолданба қабығы офлайн ашылатын PWA;
- сөйлеуді тану қолдауы жоқ браузерге қолмен енгізу режимі.

## Маңызды шектеулер

Web Speech API барлық браузерде бірдей жұмыс істемейді. `kk-KZ` сапасы құрылғыға, операциялық жүйеге және браузердің тану қызметіне байланысты. Кей браузер аудионы бұлттағы тану қызметіне жібереді. Қосымша аудио файл жасамайды және сақтамайды.
